# Projeto_C

Revisão de Prova cód em C

Implemente a estrutura de dados Pilha utilizando a linguagem de programação C.

A pilha de ser construída por meio de struct e array dinâmico.
Além da estrutura de dados, vcs também deverão criar as seguintes funções para manipular a pilha:

- Init  > iniciar
- Push  > adiciona
- Pop   > retirar
- Sort Merge > ordenação 
- Clear > deletar
